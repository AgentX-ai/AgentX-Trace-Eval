Trace · Evaluate · Monitor

AgentX (agentx.so)

How AgentX gives you oversight of the AI agents your company runs: explaining what they did, watching how they behave with real customers, and testing a change before release. It closes with what it takes to get started. Every screen shown is the product itself.

Why it is safe to run in a large enterprise

Runs entirely inside your infrastructure.

Self-hosted on your own servers or cloud account, with Docker or Kubernetes. Traces, test sets and results stay in your own database, with no AgentX account or cloud service in the path. Nothing is sent back to AgentX: no usage data, licence checks or update checks.

Your AI contracts, or your own model.

Features that send conversation text to a model (AI judges, topic labelling, written assessments, test-case generation) use the provider you choose: OpenAI, Anthropic or Gemini under your own keys and agreements, or a model you host yourself. The topic and coverage maps also use an OpenAI embeddings model.

Sign-in through your identity provider.

Single sign-on with Okta, Microsoft Entra, Google Workspace or any OIDC provider. Owners and admins decide who has access, and every project has its own access key.

An append-only audit trail.

Every configuration change, sign-in and data export is logged with who and when. Entries cannot be edited or deleted through the AgentX interface or API, and secrets are never written to the log.

Leaks flagged in agent answers.

Built-in checks flag credentials, email addresses, phone numbers, social security and card numbers, and replies that repeat known prompt-injection phrasing. They flag a reply once it is sent rather than blocking it, and make no AI calls, so they can run on all traffic.

People approve every fix.

Automated checks flag issues and AI drafts fixes, but nothing goes live until a person approves it, and each decision is recorded.

You decide how long data is kept.

Retention is set per project. Older traces are removed, and everything can be exported before they are.

Source code your security team can review.

The engine’s source is published under the Elastic License 2.0, with a private route for reporting vulnerabilities. Agents connect over the OpenTelemetry standard, and all data exports in an open format.

The document is in three parts, each answering a question leadership is asked about AI agents. Traceability: can we explain what an agent did, and who changed it? Observability: is it behaving with real customers, and is anything sensitive getting out? Evaluations: how do we know a change is safe before customers see it? A last part, Getting started, covers what it takes to run AgentX.

04 · Audit trail & export

Who changed what, what was exported, and how long data is kept

Every configuration change, sign-in and bulk export is written to an audit trail: who did it, what they touched, and whether it worked. Entries cannot be edited or deleted through the AgentX interface or API. All data can be exported in an open format, and each project decides how long it is kept.

What every audit entry records
WhoThe person or API key that acted
WhatThe action and the item it touched, such as editing a scorer or exporting traces
WhenThe time it happened
OutcomeWhether it succeeded
ChangesThe names of the fields that changed, not their values, so keys and passwords are not logged
What can be exported
Traces and conversationsSession scoresUser feedbackReported outcomesSignals and review decisionsTopic classificationsDatasets and their historyEvaluation runs and resultsCI gate resultsScorer settingsThe audit trail

Exports use an open, line-by-line format, for backup or for moving between deployments. Every export is itself recorded in the audit trail.

Retention is set per project. Under Settings › Retention, each project keeps traces for a set number of days and older ones are deleted. Export anything you need to keep longer before then.

23 · AgentX eval skill

From a failing evaluation to a reviewed code fix

Registries and proposals change the agent’s instructions. The AgentX eval skill changes its code. It is a plugin for coding assistants (Claude Code, Cursor, Codex and any assistant that supports Agent Skills) and works from the agent’s own repository in four steps: connect the agent, evaluate it, fix what the evaluation found, and re-run the same tests.

1
Connect

Connects the agent to AgentX from its own repository and checks that its runs arrive.

2
Evaluate

Builds a test set from templates, a spreadsheet or real traffic, and runs the agent through it.

3
Fix

Checks each recommendation against the code, drops the ones that do not apply, and applies the rest on a separate branch.

4
Re-test

After approval, runs the same tests again so the two versions are compared on the same cases.

24 · Install and send traffic

From install to the first trace

AgentX installs with a single command and runs on your own infrastructure. An agent connects through the telemetry it already produces or through the SDK, and no AI provider account is needed to begin.

1 · Install

One command installs AgentX on a server or a laptop and opens the dashboard. It comes with its own database, so there is nothing else to set up first.

2 · Connect an agent

Point the agent’s existing OpenTelemetry output at AgentX, or add the SDK. Its runs appear in Live Traces as they happen.

3 · Switch on the checks

Enable the built-in checks for leaked secrets, personal data and echoed prompt-injection phrasing. They need no AI provider account and cost nothing to run.

Or let a coding assistant do the setup. The AgentX eval skill, a plugin for Claude Code, Cursor, Codex and other coding assistants, connects the agent, runs a first evaluation and fixes what it finds. Section 23 covers it.

25 · CI Gates

Releases blocked when quality drops

Evaluations can run automatically whenever the agent changes. If quality falls below an agreed score, or below the previous version, the change is blocked before it ships. Every decision is recorded, and anyone can check whether the latest run would pass without starting a release.
