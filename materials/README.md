# Materials

## AgentX governance tour

[`agentx-governance-tour.html`](agentx-governance-tour.html) walks through every screen of the
self-hosted governance layer, grouped into its three pillars:

- **Traceability** - Live Traces, Sessions, trace detail and execution timeline
- **Observability** - Overview, Monitor, Topics, the Review queue, Scorers and Rules
- **Evaluations** - Datasets, evaluation runs, AI Analysis, Playground, conversation simulation,
  Model Portability, dataset coverage, the prompt and tool registries, improvement proposals and
  CI Gates

Each section reproduces the dashboard UI. All figures are demo data from a fictional project.

### Viewing it

GitHub shows `.html` files as source rather than rendering them. To view the tour, open
[the raw file](agentx-governance-tour.html?raw=1) and save it, then open it in any browser.

It is a single self-contained file. The only external request is the Inter Tight font from Google
Fonts; offline it falls back to the system sans-serif.
